Scope of result use

All times, utilizations and costs are derived values of the declared models. Networking uses a flow-level abstraction, and costs are not cloud bills; workflow deadlines are used for post-hoc observation only. Task relationships follow the dependencies in the input: the timeline shows execution order and cannot replace the dependency graph.

Self-contained offline report with no external scripts or network requests. The original configuration, metrics and event evidence are preserved alongside the report.
