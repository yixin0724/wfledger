# License Texts and Provenance

This directory contains the license texts and source records distributed with WfLedger.

| File | Source |
|---|---|
| `Apache-2.0.txt` | https://www.apache.org/licenses/LICENSE-2.0.txt |
| `CloudSim-LGPL-3.0.txt` | The pinned WorkflowSim distribution's `license.txt` |
| `WorkflowSim-GTPL-notice.txt` | The pinned WorkflowSim distribution's `license-workflowsim.txt`, retained verbatim |
| `GTPL-3.0.txt` | https://scancode-licensedb.aboutcode.org/gtpl-v3.LICENSE |

The upstream reference is WorkflowSim 1.0 at commit `d3ea21afd8ce6479bd292d3bd7469045d7a36089`.

`WorkflowSim-GTPL-notice.txt` is an upstream notice, not a claim that every WfLedger file is GTPL-covered. The upstream notice does not specify a complete per-file scope. `GTPL-3.0.txt` is the publicly documented version 3 reference text and is retained for any applicable material.

The root `NOTICE.md` explains copyright and modifications. The root `THIRD_PARTY.md` records component scope and review boundaries. The root `LICENSE` is the WfLedger project license, GPL-3.0-or-later.

Do not remove upstream notices when modifying or repackaging the project. New upstream files, dependencies, datasets, templates, and release artifacts require their own license review.
